# 기획서 — N빵 드라이브

> 접수양식(DOCX)의 항목에 옮겨 적는 원고. 숫자 중 [가정] 표시는 근거 자료로 바꿔 넣을 것.

## 1. 앱 개요
- **앱 이름:** N빵 드라이브
- **한 줄 소개:** 같이 탄 거리만큼, 운전한 수고만큼 — 동승 이동 비용을 차가 알아서 나눠 주는 정산 미터기
- **카테고리:** 모빌리티 서비스 (주행 중 제한적 표시 허용 카테고리)
- **대상:** 카풀 출퇴근 동료, 동호회·모임 이동, 친구·가족 장거리 여행

## 2. 문제
- 함께 차를 타면 "유류비/충전비를 누가 얼마나?"가 늘 애매하다. 대충 N분의 1을 하거나 운전자가 떠안는다.
- 중간에 내리는 사람이 있으면 계산이 더 어렵다. 앱으로 정산하려면 거리·인원을 사람이 직접 입력해야 한다.
- 운전자는 운전이라는 노동까지 하는데 똑같이 내는 건 불공평하다는 정서가 있지만, 얼마를 덜 내야 하는지 기준이 없다.

## 3. 해결 — 차가 직접 재고 나눈다
1. **좌석 탑승 센서**로 누가 언제 타고 내렸는지 자동 기록
2. **주행거리 + 차속**으로 함께 간 거리를 구간별로 계산 → 그 순간 탄 사람끼리 분배
3. **운전 수고 할인**: 브레이크 밟은 횟수·핸들 회전량(막히는 길·골목), 크루즈 사용, 와이퍼(비)로 운전 강도를 재서 운전자 몫을 줄인다 (기본 20% + 최대 +15% + 비 +5%, 상한 50%, 사용자 조절)
4. **자동 단가**: 차가 알려 주는 전비/연비 또는 이번 운행의 실제 배터리 소모량으로 km당 비용 산출
5. P단에서 이름 지정·통행료 추가·정산, 주행 중엔 미터기처럼 큰 숫자만

## 4. 차량특화성 — 왜 차 안에서만 되는가
| 필요한 정보 | 휴대폰 앱 | N빵 드라이브 |
|---|---|---|
| 누가 탔나·언제 내렸나 | 사람이 입력 | 좌석 탑승 센서 자동 |
| 함께 간 거리 | GPS 추정, 사람별 구분 불가 | 주행거리·차속 + 승하차 시점 |
| 실제 쓴 에너지 | 모름 (평균 연비 가정) | 전비·배터리 소모 실측 |
| 운전 노동 강도 | 모름 | 브레이크·핸들·크루즈·와이퍼 |

## 5. Pleos SDK 활용
| SDK / API | 쓰는 값 | 기능 |
|---|---|---|
| Vehicle – Seat | 좌석별 탑승 | 승하차 기록 |
| Vehicle – Gear | P/D | 주행/정차 화면 전환 |
| Vehicle – Odometer | 누적 주행거리 | 구간 거리(기준) |
| Vehicle – Brake, SteeringWheel, DrivingMode(크루즈), Wiper | 운전 강도 | 운전 수고 할인 |
| Vehicle – EvBattery, Fuel | 전비·연비·배터리 잔량 | 자동 단가 |
| AAOS 표준 PERF_VEHICLE_SPEED | 차속 | 주행거리 사이 보간 |

## 6. 화면 설계 (운전자 주의분산 가이드 준수)
- **주행 중:** 총액(72sp) + 사람별 금액 + 운전 강도 한 줄. 버튼 없음. `distractionOptimized` 선언
- **정차(P) 중:** 좌석 배치도(이름 지정), 정산 목록, 단가·수고 할인 설정, 통행료 버튼, "정산 끝·새 운행"
- 가로(2칸)/세로(1칸) 모두 대응: 너비 900dp 기준 2단/1단 전환

## 7. 사업성
- **타깃:** ① 카풀 출퇴근(같은 회사·같은 방향 동료) ② 정기 모임·동호회 이동 ③ 가족·친구 장거리 여행
- **MAU 추정 방법:** Pleos 탑재 차량 수 × 동승 이동 비율 × 앱 사용률
  - 예: 탑재 차량 [가정] 10만 대 × 정기 동승 비율 [가정] 20% × 사용률 [가정] 15% = 약 3,000 MAU (출시 1년 차)
  - 근거로 바꿔 넣을 자료: 통근 수단·카풀 이용 통계, 평균 재차 인원
- **리텐션:** 카풀은 주 5회 반복 사용, 정산 기록이 쌓일수록 이탈 비용 증가 (월간 정산 리포트)
- **수익 모델:** ① 정산 결과 송금 연동 수수료(제휴) ② 법인 카풀 프로그램(B2B, 직원 카풀 지원금 증빙) ③ 보험사 제휴 — 카풀 운행 기록 기반 특약
- **확장:** 정산 결과 QR → 폰 송금 링크 / 하이패스 통행료 자동 반영 / 내비 경유지 = 하차 지점 기록 / 법인 차량 운행기록부 연계

## 9. 2차 PT 시연 시나리오 (2분)
1. 정차: 운전자·동료 2명 탑승 → 좌석 카드에 이름 지정
2. 출발(D): 화면이 미터기로 전환, 시내 가다 서다 → "운전 강도 힘듦 · 운전자 32% 할인"
3. 정차 후 뒷좌석 하차 → 다시 출발, 비 + 크루즈 고속도로
4. 도착(P): 사람별 금액·함께 간 거리·운전 수고 할인액 확인 → "정산 끝"
